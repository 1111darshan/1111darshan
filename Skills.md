Company Technology Skill Matrix

Purpose

This skill defines the technologies, tools, platforms, services, and sub-skills
used by different companies.

The data is intended for an AI Career & Job Assistant to:

* Match candidate skills against company technology stacks.
* Identify missing skills.
* Analyze job requirements.
* Recommend technologies to learn.
* Provide official websites and documentation.
* Generate company-specific learning roadmaps.
* Generate company-specific interview preparation.
* Calculate technology and skill compatibility.

⸻

Table Schema

Column	Description
Skill Category	High-level technology category
Company	Company using the technology
Skill / Technology	Main technology, platform, or tool
Sub-Skill	Specific service, component, or capability
Official Website	Official vendor/project website
Official Documentation	Official documentation or reference
